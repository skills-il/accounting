# Changelog

All notable changes to this skill are documented here.

## [1.6.1] - 2026-10-18

### Changed

- התיאור נפתח ב"אינו ייעוץ מס ואינו דוח שהוגש." / "Not tax advice and not a filed return." בשני קובצי הסקיל וב-metadata.json.
- שיעור האפס לשירות לתושב חוץ מנוסח בזהירות: "בדרך כלל" לפי סעיף 30(א)(5) לחוק מע"מ, כשמתקיימים תנאיו (שלב 3 בשתי השפות ו-Workflow 4).
- דוגמת הסכמה ב-api-reference מסומנת כמצייני מקום שאינם מסמך מאוזן.

### Added

- הסקריפט: דגל `--b2b` לקונה שהוא עוסק מורשה או חברה, ובדיקת מספר הקצאה לפי הסף שבתוקף בתאריך המסמך (לפני מע"מ, בשקלים, "עולה על"). אזהרה כשחסר `--tax-id`, ואזהרה כשתשובת היצירה מראה שלא נשלחה בקשה לרשות המסים. הסכום מנוטרל ממע"מ בשורה שהמע"מ כלול בה ומומר לפי `--currency-rate` במסמך במטבע זר.

## [1.6.0] - 2026-10-18

### Changed

- מסלול `/account/token` הישן הוסר ב-sandbox, ולכן האימות שם הוא OAuth 2.0 בלבד; הסקריפט עבר ל-OAuth כברירת מחדל.
- Webhooks זמינים ממסלול Best לפי מרכז העזרה הנוכחי; ברירת המחדל של `currencyRate` היא 1; יצירת מסמך מחזירה 201.
- עוסק מורשה סוגר חשבון עסקה ב-320 בזמן התשלום; מספר הקצאה חסר מבוקש לחשבונית הקיימת (סעיף 47(א2)(4)), כולל מסלול הסירוב וסעיף 40ב.
- נוספו כללי ניכוי מע"מ תשומות (סעיפים 38(א) ו-38(א2)) והבהרה משפטית אחרי הכותרת.

### Fixed

- הוסרו פרטים שלא נמצאו במפרט: שגיאת "Client email required", טבלת קטגוריות עסק, ערך מיון creationDate ושדות סכמה.
